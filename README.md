# Stock Trading Platform

A Java-based Stock Trading Platform developed using Object-Oriented Programming concepts.

## Features
- Stock management
- User portfolio tracking
- Buy and sell transactions
- Market data handling

## Technologies Used
- Java
- Maven
- OOP Concepts

## Project Structure
- Stock.java
- User.java
- Portfolio.java
- Transaction.java
- Market.java
